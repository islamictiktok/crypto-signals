# Triangle Spot Hunter

هذا هو الإصدار الأخير من البوت. يعمل كصياد فرص Spot ويبحث في أسواق USDT المؤهلة، ثم يطبق استراتيجية المثلث المتقارب الظاهرة في الصورة: مقاومة هابطة، دعم صاعد، انكماش في النطاق، كسر صاعد، تأكيد متعدد الفريمات، وأهداف مبنية على ارتفاع المثلث.

> أنا لست مستشاراً مالياً مرخصاً. هذا النظام برمجي وتجريبي وليس ضماناً للربح. أبقِ التداول الورقي مفعلاً ولا تستخدم أموالاً حقيقية قبل إجراء اختبارات مستقلة.

## طريقة العمل

يبدأ البوت بتحميل أسواق Spot النشطة المقومة بـ USDT، ثم يجلب tickers جماعياً ويرتب الرموز حسب `quoteVolume`. يفحص أعلى 300 رمز مؤهل افتراضياً. لكل رمز، يجلب بيانات 1D و4H و1H و15M و5M ويبحث عن نمط مثلث متقارب.

لا تظهر إشارة إلا إذا كان خط المقاومة هابطاً وخط الدعم صاعداً، وكان عرض المثلث قد انكمش بنسبة كافية، وأغلق السعر فوق المقاومة مع هامش ATR أو نفذ إعادة اختبار ناجحة. يجب أيضاً أن يكون اتجاه 4H داعماً، وأن تؤكد فريمات 1H و15M و5M الزخم، وأن يكون حجم الكسر أعلى من متوسط الحجم.

## الأهداف

تُحسب الأهداف من ارتفاع المثلث، وبالقيم الافتراضية التالية:

| الهدف | الامتداد | البيع الجزئي |
|---|---:|---:|
| TP1 | 1.000 | 30% |
| TP2 | 1.618 | 30% |
| TP3 | 2.618 | 20% |
| TP4 | 4.236 | 20% |

عند تحقق أحد الأهداف في Paper Trading، يضع البوت علامة ✅ أمام الهدف، ويحدث الكمية المتبقية وPnL. ثم يعدّل الرسالة الأصلية نفسها في Telegram عبر `editMessageText` بدلاً من إنشاء رسالة جديدة. وعند تحقق TP4 تتحول الحالة إلى `CLOSED — TP4`.

## عدد الصفقات

لا يوجد حد يومي لعدد الإشارات، والتبريد الزمني الافتراضي يساوي صفراً. منع تكرار نفس الكسر يتم بواسطة `signal_id` مبني على الرمز ووقت شمعة الكسر ومستوى الكسر. توجد صفقة نشطة واحدة في الوقت نفسه كحاجز تعرض، لذلك تأتي الصفقات بالتتابع وليس على شكل تراكم غير محدود في اللحظة نفسها.

## التشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.video.example .env
set -a; source .env; set +a
python main.py
```

لا تضع مفاتيح Telegram داخل الكود أو داخل Git. عرّف `TELEGRAM_TOKEN` و`CHAT_ID` في البيئة فقط.

## الإعدادات الأساسية

| المتغير | القيمة الافتراضية | الوظيفة |
|---|---:|---|
| `SPOT_MODE` | `true` | تشغيل Spot شراء فقط بلا رافعة. |
| `VIDEO_SCAN_UNIVERSE` | `true` | البحث في قائمة العملات بدلاً من رمز واحد. |
| `VIDEO_TOP_COINS_LIMIT` | `300` | عدد الرموز الأعلى حجماً بعد الفلترة؛ القيمة `0` تعني كل الرموز المؤهلة. |
| `VIDEO_MIN_24H_VOLUME` | `5000000` | أقل حجم تداول يومي بالـ USDT. |
| `VIDEO_SCAN_CONCURRENCY` | `4` | عدد طلبات تحليل الرموز المتزامنة. |
| `VIDEO_POLL_SEC` | `300` | الفاصل بين دورات مسح السوق. |
| `TRIANGLE_MIN_CONTRACTION` | `0.15` | الحد الأدنى لانكماش المثلث. |
| `TRIANGLE_BREAKOUT_BUFFER_ATR` | `0.15` | هامش تأكيد الكسر فوق المقاومة. |
| `TRIANGLE_MIN_VOLUME_RATIO` | `1.20` | أقل نسبة حجم للكسر إلى متوسط الحجم. |
| `TRIANGLE_MAX_CHASE_PCT` | `0.02` | رفض مطاردة السعر بعد ابتعاده أكثر من 2%. |
| `TRIANGLE_EXTENSIONS` | `1.0,1.618,2.618,4.236` | امتدادات TP1 إلى TP4. |
| `SPOT_TP_ALLOCATIONS` | `30,30,20,20` | نسب البيع الجزئي. |
| `VIDEO_COOLDOWN_HOURS` | `0` | لا يوجد تبريد زمني بين الإشارات. |
| `PAPER_TRADING` | `true` | يبقي كل العمليات محاكاة ورقية. |

## الرسائل

رسالة الصفقة تعرض الرمز، `BUY LIMIT`، مستوى الدخول، الاستوب، نسبة المخاطرة، حركة 24 ساعة، RSI، تقييم المحللين، مستوى الكسر، ارتفاع المثلث، وTP1–TP4. عند تحقق أي هدف تُعدّل نفس الرسالة ويظهر ✅ أمام الهدف، مع تحديث `Current` وPnL والكمية المتبقية.

## الاختبار

```bash
python3 -m py_compile main.py
python3 -m unittest discover -s tests -v
```

الإصدار الحالي لا يحتوي على استدعاءات تنفيذ أوامر حقيقية. اختبار وصول السعر إلى الهدف وتعديل الرسالة يتم في Paper Trading فقط، ويجب إجراء Backtest وForward Test شاملين مع الرسوم والانزلاق قبل أي ربط تنفيذي.
